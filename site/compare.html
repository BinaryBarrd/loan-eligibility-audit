Type one person’s details once. The calculators ask for different things, so each one gets only what it asks for, in its own boxes. Under each name you can see exactly what it was given.

  • Calculators with one “expenses” box (Bajaj Finserv, Axis, Fibe, Aditya Birla) get your EMIs plus other expenses.
  • Calculators that ask only for EMIs (Paisabazaar, Kotak, SMFG, Poonawalla) get your EMIs; other expenses are left out.
  • IDFC FIRST gets EMIs as EMIs and other expenses as “utilities”. Age is used only by Paisabazaar; rate and tenure only where a calculator asks.
  • If a value is outside a calculator’s own range, it says so instead of guessing.
